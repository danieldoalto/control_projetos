A IA não deve reescrever partes funcionais existentes sem necessidade.
Cada etapa deve preservar o funcionamento já implementado.
Antes de modificar uma interface existente, deve verificar suas dependências.
Alterações incompatíveis devem ser explicitamente justificadas.
Simplicidade sobre complexidade desnecessária.
O código deve ser modular, incremental e determinístico.
Usar arquivos de configuração para definir parâmetros, em vez de hardcoding.
Nunca armazenar chaves de API ou dados sensíveis no código.
Evitar refatorações em massa sem necessidade explícita.
Perguntar antes de alterar especificação.
Se a especificação estiver ambígua, deve pedir esclarecimentos antes de implementar.
Quando possível, usar interfaces já existentes, em vez de criar novas.
Sempre que ouver uma modificação ou melhora explicar e perguntar o que fazer.
